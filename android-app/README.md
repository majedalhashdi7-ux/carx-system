# 📱 Android App - HM CAR

> [!IMPORTANT]  
> **هذا المجلد (android-app/) هو تطبيق Android Native بلغة Kotlin**  
> **التطبيق الفعّال والمكتمل هو مجلد `mobile-app/` (React Native / Expo)**

## مسارات تطوير التطبيق

| المجلد | التقنية | الحالة |
|--------|--------|-------|
| `mobile-app/` | React Native + Expo | ✅ فعّال ومكتمل |
| `android-app/` | Android Native (Kotlin) | 🚧 هيكل أساسي فقط |

## ماذا تستخدم؟

استخدم **`mobile-app/`** لأنه:
- يعمل على iOS وAndroid معاً
- مرتبط بـ API النظام
- يحتوي على شاشات كاملة (السيارات، قطع الغيار، المزادات، الطلبات)

## تشغيل `mobile-app/`

```bash
cd mobile-app
npm install
npx expo start
```
